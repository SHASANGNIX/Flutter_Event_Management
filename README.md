# 📱 Velora - Campus Event Manager

A Flutter-based mobile application designed to simplify event management and event discovery within educational institutions.

Velora enables students and organizers to create, manage, search, and explore campus events through an intuitive and modern user interface.

---

## 🚀 Features

### 🎯 Event Management

* Create new events
* Edit existing events
* Delete events
* View complete event details

### 🔍 Event Discovery

* Search events by name
* Browse upcoming events
* Filter and organize event listings

### 📅 Event Information

* Event date and time
* Venue details
* Department information
* Event category
* Registration details
* Contact information

### 🎨 Modern UI

* Beautiful Flutter UI
* Responsive design
* Smooth user experience
* Material Design components

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/SHASANGNIX/Flutter_Event_Management.git
```

### Navigate to Project

```bash
cd Flutter_Event_Management
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```
